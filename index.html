About Me

Hi, I’m Jamie Alonzo, a Software Developer and Web Developer based in Los Angeles with a passion for turning creative ideas into interactive, secure, and scalable digital experiences. Whether I’m crafting sleek, user-friendly interfaces, designing dynamic websites, or engineering the complex backend logic that powers them, I thrive on bringing projects to life from start to finish. I specialize in designing and developing innovative software and web solutions that transform complex problems into elegant, user-focused applications. My commitment to continuous learning and love for experimentation keep me at the forefront of the latest technologies, enabling me to write cleaner, smarter, and more efficient code with every project. When I’m not coding, you’ll likely find me binge-watching anime with my dog, Tato, or brainstorming my next big idea. From exploring new frameworks to tackling challenging puzzles, I’m always ready for my next adventure both in tech and in life. Explore my portfolio to see how I combine creativity, technical expertise, and a drive for innovation to build software and websites that truly make a difference.

Projects

Anime Empire

A sleek and fully responsive e-commerce store designed on Shopify, featuring a curated collection of anime-inspired T-shirts, hoodies, gym wear, and accessories. Built with custom styling and user-friendly navigation, Anime Empire offers fans a seamless shopping experience to express their passion through high-quality apparel. This project demonstrates expertise in Shopify's platform, design customization, and e-commerce functionality.

Brooki Bakery

This project is a WordPress-powered website created for a fictional bakery specializing in custom cakes and cookies. The site features a modern, user-friendly design with sections like an "About Us" page, a vibrant product gallery, customer reviews, and a "Follow Us" page to encourage social media engagement. I focused on creating a warm and inviting digital presence that reflects the bakery’s brand identity while ensuring easy navigation and a seamless user experience.

AcademIQ (In Progress)

A Tutor App that is an ongoing project designed to connect students with qualified tutors, offering both online and in-person learning options. The app provides a seamless experience for parents to track student progress, find nearby tutors, and schedule sessions with ease. With a focus on convenience, accessibility, and personalized learning, the platform aims to make tutoring more efficient and engaging. Key features include location-based tutor searches, real-time progress tracking, and a user-friendly interface that ensures a smooth experience for both students and parents. Currently in development, this project highlights my UI/UX design skills, front-end development expertise, and problem-solving abilities as I refine the app’s functionality and user experience.

The Health & Nutrition Tracker is a web application that enables users to easily track their daily food intake and access detailed nutritional information using the Nutritionix API. Built with HTML, CSS, and JavaScript, it offers a modern design optimized for both desktop and mobile use.
